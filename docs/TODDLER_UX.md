# TODDLER_UX.md
## Designing for 2-year-olds — non-negotiable constraints

### The 2-year-old user model
- Cannot read
- Cannot follow verbal/text instructions
- Attention span: 2–4 minutes per session
- Motor precision: low — fingers land 15–20pt off intended target
- Emotional response: immediate — boredom and frustration happen fast
- Learning style: trial and error, immediate reward loop
- Does not understand "rules" — discovers through exploration

### What works
- Big colorful objects that react immediately to touch
- Sound + animation + haptic together on every tap
- Silly character reactions (Pedro wobbling, jumping, making sounds)
- Clear "something happened" feedback in < 100ms
- Short loops: tap → reaction → reward → next tap
- Familiar objects (animals, vehicles, food)

### What breaks the experience
- Any loading time visible to the child
- Text of any kind in the play area
- Timers or countdowns (creates anxiety)
- Complex gestures (pinch, multi-touch, long press)
- More than 3 taps needed to reach the game
- Anything that looks like "game over" or "wrong"
- Sounds that are scary or too loud

### Tap target rules
- Minimum: 90×90pt
- Recommended: 110×110pt for primary targets
- Cards in Memory game: 90×120pt ✓
- Spacing between targets: minimum 8pt (prevent accidental hits)

### Session flow (Memory Match for age 2)
1. App opens → Pedro appears floating, happy sound
2. One tap on "Play" (big button with airplane icon, no text)
3. Cards appear with a deal animation (satisfying)
4. Child taps cards — each tap has immediate sound + flip
5. Pair found → Pedro jumps, sparkle sound, cards light up green
6. Mismatch → gentle wobble, soft "boing" sound, cards flip back
7. All pairs → big celebration, Pedro dances, confetti, win fanfare
8. "Play again" button (circular arrow icon)
Total time: 3–5 minutes max

### What Sago Mini does that we copy
- No wrong answers: the wrong action just does something fun
  (Sago Mini principle: "yes and...")
- Character reacts to EVERYTHING, not just correct actions
- Backgrounds have Easter egg interactions (tap the cloud → rain drops)
- Music is gentle, looping, non-intrusive
- Every screen has exactly ONE primary action
